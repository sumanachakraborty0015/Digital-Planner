📅 Connect Google Calendar

One-time setup (~10 minutes).

1
Go to Google Cloud Console
Open console.cloud.google.com. Sign in with your Google account.
2
Create a project
Project dropdown → New Project → name it SC-Digital-Planner → Create.
3
Enable Google Calendar API
Menu → APIs & Services → Library → search "Google Calendar API" → Enable.
4
OAuth consent screen
External → App name: SC Planner → Save. Add yourself as Test user.
5
Create OAuth credentials
Credentials → OAuth 2.0 Client ID → Type: Web application. Copy the Client ID.
6
Paste your Client ID below
